# Boss 02 - Flappy Bird

Things added:

 - Selection between easy mode (From base game) and hard mode via strategy pattern.
 - Hard mode includes an invincibility PowerUp, opening and closing log pairs, uneven spacing between log pairs, hability to move the bird horizontally.
 - GameOver Screen, makes the bird fall to the ground
 - Pause Screen (Pause with "p")
 - Add jump with spacebar (Personal choice)
 - Make the bird rotate according to his fly direction,  just like the original flappy bird

Minor Fixes

 - Add world boundary to the top of the screen, so you can't spam the jump and get over the logs
