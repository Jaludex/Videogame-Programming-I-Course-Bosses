# Boss 07 - Ultimate Fantasy

Things added:

 - In-World menu for checking the stats of every character in the party and, if possible, use moves that are targeted to allies off-battle (Only healing for now but compatible with any move targeted to an ally)
 - Change the battle system to a time based one, each battle entity now includes a cooldown_timer attribute, when the battle is on, the battle entities only attacks when their timer is completed, altering the turn taking dynamic. Includes a progress bar for each entity in battle for knowing when they're going to attack
